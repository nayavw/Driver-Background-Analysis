# Driver-Background-Analysis
CS 2316 Final Project

My data collection and analysis aims to identify trends and correlations between a driver's home country financial status and overall success in the sport. This is towards supporting my hypothesis that driver's that come from countries with higher financial indictors (PPP, GDP, and GDP per capita) will exhibit more success in the sport as they have a wealthier background. The insights and visualization of the found data will hopefully provide some clarity to the data as it is a lot of data to sort through. The data needs to be manipulated to be interpreted as there are many cross-references that need to be made across the different datasets.
